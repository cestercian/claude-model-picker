# claude-model-picker

A Claude Code skill for choosing between Claude Haiku 5.5, Sonnet 5.5, Opus 5.5 and Fable 5.2 — and the right effort level — for a task, subagent, or API integration.

Condensed from Anthropic's playbook *Which Claude model should you build with?* (Nov 2026).

## Install

```bash
git clone https://github.com/cestercian/claude-model-picker ~/.claude/skills/claude-model-picker
```

Then ask Claude things like "which model should I use for this?" or "make my subagents cheaper".
